# Orchnex System Overview

Orchnex is a multi-LLM orchestration platform designed to pair the specialized reasoning and feedback capabilities of Meta's Llama models with the generation capabilities of Google's Gemini models.

The system works by creating a dual-agent configuration:
- **PromptMaster (powered by Llama)**: Responsible for analyzing raw user input, generating detailed context-enhanced prompts, and critiquing output generated by other models.
- **Phoenix (powered by Gemini)**: A creative and analytical generation engine that takes context-enriched prompts and produces high-quality, comprehensive responses.

By running these two models in an iterative loop, Orchnex resolves ambiguity in user queries, checks generated content against strict validation standards, and refines response quality automatically without manual user intervention.
